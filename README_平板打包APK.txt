照片氣氛動畫播放器 Android APK 專用修正版
APK 版本：v0.3.11
直接來源：v0.3.10 APK 平板實測版
保留基準：v0.3.8 / Build APK #21 成功安裝版

本版只針對 APK / Android WebView 與平板實測問題調整，不改原本網頁母版；v0.3.8、v0.3.9、v0.3.10 均保留，不覆蓋。

本次修正／調整：
1. MP3 → MP4 閃爍：移除影片 canplay 階段反覆重設 currentTime 的做法；改成載入時只強制同步一次，播放中僅在時間差明顯時低頻校正，避免影片像快轉般反覆跳格。
2. 播放清單入口：播放介面的「播放清單」會明確切換到播放清單頁。
3. 播放清單匯入：匯入後即使當下沒有已載入的音樂，也會顯示清單；若同一台 Android 裝置仍有可長期讀取的檔案 URI，會嘗試直接恢復。
4. 播放清單刪除：新增「清空」按鍵；原本單曲長按移除保留。
5. 重開 App 恢復：音樂清單、可長期讀取的字幕檔、背景照片／影片會保存 Android 文件 URI，重新開啟 App 時嘗試恢復，不再只保留空清單。
6. 全螢幕退出：全螢幕中新增「由畫面中間往右滑」退出手勢，不必只靠最邊緣的 Android 返回手勢；系統返回仍可退出全螢幕。
7. 全螢幕尺寸：進入／退出 Android 原生全螢幕後，分階段重新計算播放器尺寸，避免剛進去時殘留主畫面木紋邊，必須滑一下才鋪滿。
8. 主畫面邊框：胡桃木／胡桃木＋米色主題增加左右木紋留白；播放區採黑色框＋低調霧面古金細線，金色不偏亮黃；全螢幕完全取消外框。
9. APK 圖示：繼續使用使用者最後上傳並自行裁切的女生圖原檔，不重新生成、不重畫、不加播放符號。
10. GitHub Actions：維持只在 .build-trigger 更新或手動 Run workflow 時打包，避免 ZIP 每個檔案各觸發一次。

- 上方工具列、下方播放控制列維持原有配置。
